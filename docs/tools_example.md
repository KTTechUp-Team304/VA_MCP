## OWASP Top 10 도구 후보군 (1차 / 2차)

모든 항목을 한 번에 구현하지 않고, `scenario` 조립 구조에 맞춰 단계적으로 확장한다.

---

## 1차 (MVP: scenario 진입점 + 자동화 가능한 핵심)

### [공통 / 탐색]
- API 자산 목록화
- OpenAPI / Swagger 파싱
- 엔드포인트 탐지
- 파라미터 추출

### [접근 제어]
- 역할 기반 접근 제어 테스트 (기본)
- IDOR / BOLA 테스트 (기본)
- BFLA 테스트 (기본)
- 강제 브라우징
- HTTP 메서드 변조 테스트
- 파라미터 변조 테스트

### [보안 설정 오류]
- 보안 헤더 분석
- CORS 오설정 테스트
- 민감 경로 탐지
- 디버그 엔드포인트 탐지
- 오류 정보 노출 테스트
- 디렉터리 목록 노출 탐지
- 기본 설정 취약점 탐지

### [암호화 실패]
- 민감 정보 노출 탐지 (기본 패턴)
- 안전하지 않은 JWT 분석
- 쿠키 보안 속성 점검

### [인젝션]
- SQL 인젝션 테스트 (기본 페이로드 세트)
- 명령어 인젝션 테스트 (기본 페이로드 세트)
- 경로 순회(Path Traversal) 테스트
- 헤더 인젝션 테스트
- 반사형 XSS 탐지

### [인증 실패]
- 로그인 시도 제한(Rate Limit) 테스트
- 무차별 대입(Brute Force) 방어 테스트 (기본)
- 계정 잠금 정책 테스트
- 세션 만료 처리 테스트
- JWT 만료/서명 검증 테스트
- 계정 유무 추측(Credential Enumeration) 탐지

### [예외 처리 미흡]
- 비정상 입력(Malformed Input) 테스트
- 타임아웃 처리 점검
- 재시도(Retry) 처리 점검
- 스택 트레이스 노출 테스트
- 오류 코드 일관성 점검

---















## 2차 (확장: 복잡한 상태 관리/환경 의존/정밀도 강화)

### [공통 / 탐색]
- 요청 재실행(Request Replay)
- 응답 비교 분석
- 인증 컨텍스트 전환

### [접근 제어]
- 대량 할당(Mass Assignment) 테스트
- SSRF 파라미터 테스트

### [보안 설정 오류]
- TLS 설정 점검

### [소프트웨어 공급망]
- 의존성 목록화
- 알려진 취약점 매칭
- Lockfile 무결성 점검
- 패키지 무결성 검증
- 타이포스쿼팅(Typosquatting) 탐지
- 구버전 의존성 탐지
- 도커 이미지 분석
- CI/CD 설정 검토
- 시크릿 패턴 탐지
- SBOM 생성

### [암호화 실패]
- 평문 전송 탐지
- 약한 TLS / Cipher 탐지
- 약한 해시 알고리즘 탐지
- 안전하지 않은 시크릿 저장 패턴 탐지
- 인증서 검증 점검

### [인젝션]
- NoSQL 인젝션 테스트
- LDAP 인젝션 테스트
- 템플릿 인젝션 테스트
- XXE 테스트
- 저장형 XSS 탐지

### [안전하지 않은 설계]
- 비즈니스 로직 악용 테스트
- 워크플로우 우회 테스트
- 자원 남용/Rate Limit 우회 테스트
- Abuse Case 체크리스트 평가
- 위협 모델링 체크리스트 평가
- 상태 전이(State Transition) 테스트
- 다단계 흐름 검증
- 권한 경계 검토

### [인증 실패]
- 비밀번호 정책 테스트
- 세션 고정(Session Fixation) 테스트
- MFA 우회 점검
- API Key 범위(Scope) 검증

### [소프트웨어 및 데이터 무결성 실패]
- 웹훅 서명 검증 테스트
- 파일 업로드 무결성 테스트
- 안전하지 않은 역직렬화 테스트
- 서명 없는 업데이트 점검
- 클라이언트 측 무결성 점검
- 빌드 산출물 무결성 점검
- 데이터 변조 탐지
- 캐시 오염(Cache Poisoning) 테스트

### [보안 로깅 및 경보 실패]
- 감사 로그 범위 점검
- 보안 이벤트 로깅 테스트
- 로그인 실패 로그 점검
- 권한 변경 로그 점검
- 민감 정보 로그 기록 탐지
- 경보 트리거 검증
- 로그 변조 저항성 점검
- 사고 추적 가능성 점검

### [예외 처리 미흡]
- 예외 퍼징(Exception Fuzzing)
- 장애 주입(Fault Injection) 테스트
- 점진적 성능 저하 대응(Graceful Degradation) 테스트
