실행 순서
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

PROBE-1: 카나리 페이로드 — 각 파라미터에 순서대로 삽입
페이로드:
- {{7*7}}
- ${7*7}
- <%= 7*7 %>
- #{7*7}

응답 body에 "49" 포함 여부 확인

PROBE-2: 엔진별 확인 (PROBE-1에서 49 반환 시)
- Jinja2: {{config}}
- Twig: {{_self}}
- Freemarker: ${7*7}
- ERB: <%= 7*7 %>

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
판단 기준
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

- 응답 body에 "49" 포함 → VULNERABLE
- 엔진별 페이로드로 설정 정보 / 환경변수 노출 → CRITICAL로 상향
- 응답 body에 "49" 없음 → PASSED

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
severity 매핑
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

| 조건                                  | severity | confidence |
|---------------------------------------|----------|------------|
| 49 반환 + 설정/환경변수 노출          | CRITICAL | HIGH       |
| 49 반환 (템플릿 실행 확인)            | HIGH     | HIGH       |
| 모든 PROBE PASSED                     | PASSED   | HIGH       |

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
evidence 작성 형식 (이 형식을 반드시 따르세요)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  [요청] {METHOD} {URL}
  [페이로드] {파라미터명}={삽입한 페이로드}
  [응답] {status_code} / elapsed: {elapsed_seconds}s
  [body 발췌] {"49" 또는 노출된 설정/환경변수 200자 이내}
  [엔진] {추정 템플릿 엔진명}

  ※ 추론 금지. 실제 execute_probe 결과만 기재.
