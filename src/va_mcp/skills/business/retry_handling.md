PROBE-1: 정상 요청 2회 연속 전송
- 완전히 동일한 body로 2회 요청
- 두 번째 요청의 status_code + body 기록

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
판단 기준
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

- 두 번째 요청도 201 반환 → VULNERABLE (중복 처리)
- 두 번째 요청에서 409 Conflict 반환 → PASSED
- 두 번째 요청에서 422 / 400 반환 → PASSED (서버 측 검증)
