tool_id: error_info_exposure
category: A02
설명: 응답 헤더 및 에러 응답에서 서버/프레임워크 정보 노출 여부 탐지.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
실행 순서
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

PROBE-1: 정상 요청 응답 헤더 확인
- 타깃 엔드포인트에 정상 요청 전송
- 응답 헤더에서 X-Powered-By, Server 값 확인

PROBE-2: 비정상 파라미터 전송 후 헤더 확인
- body 필드에 null byte(\x00), 특수문자(', ", <, >) 삽입
- 응답 헤더에서 X-Powered-By, Server 값 확인
- 응답 body에서 스택 트레이스, 프레임워크명, 버전 노출 여부 확인

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
판단 기준
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

- X-Powered-By 헤더 존재 → VULNERABLE
- Server 헤더에 버전 정보 포함 (예: nginx/1.18.0, Apache/2.4.41) → VULNERABLE
- Server 헤더에 서버명만 존재, 버전 없음 → INFO
- 응답 body에 프레임워크명/버전/경로 노출 → VULNERABLE
- 두 헤더 모두 없음 → PASSED

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
severity 매핑
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

| 조건                                        | severity | confidence |
|---------------------------------------------|----------|------------|
| X-Powered-By 존재                           | MEDIUM   | HIGH       |
| Server 헤더에 버전 포함                     | MEDIUM   | HIGH       |
| body에 스택 트레이스 / 경로 / 버전 노출     | HIGH     | HIGH       |
| Server 헤더에 서버명만 존재                 | INFO     | HIGH       |
| 모든 PROBE PASSED                           | PASSED   | HIGH       |

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
evidence 필수 포함 항목
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

- 요청 URL + 사용한 페이로드
- X-Powered-By 헤더 값 (존재 시)
- Server 헤더 값 (존재 시)
- 노출된 body 내용 발췌 (존재 시)
